# Plans

Implementation plans for major work. Per `docs/working-agreement.md` §14, larger changes (new asset class, new sync provider, new AI tool category) get an ADR first, then a plan here, then PRs.

## Format

- `00-master-plan.md` — the umbrella plan covering multiple tracks
- `NN-track-X.md` — per-track plans, numbered by Track letter
- Each plan contains: scope (in/out), files to create/modify, migrations, tests, ADRs, perf-budget impact, security checklist, rollout, PR sequence (each < 500 lines), definition of done, open questions
